## 1. Зарегистрированный сервер (Node 1)

* **Локация:** 🇳🇱 Нидерланды (Амстердам)
* **Процессор:** 1 × 3.3 ГГц CPU
* **Оперативная память:** 1 ГБ RAM
* **Дисковое пространство:** 15 ГБ NVMe
* **Скорость интернет-канала:** 1000 Мбит/сек (1 Gbps)
* **Стоимость:** 1 300 ₽ / месяц
* **Целевое назначение:** Входная точка (Edge Relay) + протоколы VLESS Reality и Hysteria 2

---

## 2. Что необходимо предоставить для начала настройки

Для того чтобы агенты команды DevOps/Security подключились и развернули серверную часть VPN ядра (sing-box / Reality / Hysteria 2):

### Необходимые данные:
1. **IPv4-адрес сервера** (например: `185.120.xx.xx`).
2. **Порт SSH** (по умолчанию `22`).
3. **Логин** (по умолчанию `root`).
4. **Пароль root** (или подтвердить привязку SSH-ключа).
5. **Операционная система** (Рекомендуется **Ubuntu 22.04 LTS** / **Debian 12**).

---

## 3. Что будет развернуто на сервере сразу после подключения

1. **Базовая защита и Hardening:**
   * Отключение SSH авторизации по паролю (перевод на ed25519 ключи).
   * Настройка файрвола UFW (открыты только порты 443 TCP/UDP и SSH).
   * Установка `fail2ban` для защиты от брутфорса.
2. **Ядро sing-box v1.11+:**
   * Inbound 1: **VLESS + XTLS Reality** (маскировка под `dl.google.com` / `microsoft.com` на 443 TCP, SNI uTLS).
   * Inbound 2: **Hysteria 2** (Salamander обфускация UDP на случай замедления TCP).
   * Outbound: Прямой выход в интернет с включенным BBR TCP congestion control.
3. **Генерация конфигураций и ключей:**
   * Публичные/приватные ключи Reality (X25519).
   * ShortId для защиты от зондирования ТСПУ.
   * Конфиг для мобильного приложения Flutter.
